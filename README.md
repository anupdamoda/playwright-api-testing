# Playwright API Testing

This repository contains a Playwright-based API test suite for validating authentication and expense-related endpoints. It uses Playwright's request API, environment variables for configuration, and reusable helpers/fixtures to keep tests clean and maintainable.

## Features

- Automated API testing with Playwright
- JWT-based login flow for authenticated requests
- Reusable API helpers and test fixtures
- Expense CRUD validation scenarios
- HTML test reports generated by Playwright
- Simple environment-based configuration

## Tech Stack

- Node.js
- Playwright Test
- JavaScript
- dotenv for environment management

## Prerequisites

Before running the tests, make sure you have:

- Node.js installed
- npm installed
- A valid backend API base URL
- Credentials for the login endpoint

## Setup

1. Clone the repository:

```bash
git clone https://github.com/anupdamoda/playwright-api-testing.git
cd playwright-api-testing
```

2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file in the project root with the required values:

```env
BASE_URL=https://your-api-base-url
API_EMAIL=your-email@example.com
API_PASSWORD=your-password
```

Example:

```env
BASE_URL=http://localhost:3000
API_EMAIL=testuser@example.com
API_PASSWORD=secret123
```

## Running Tests

The repository includes a few scripts for different test scopes:

```bash
npm run test:api
npm run test:auth
npm run test:expense
npm run test:validation
```

### Script explanations

- `npm run test:api` runs the full API test suite
- `npm run test:auth` runs the authentication tests
- `npm run test:expense` runs the expense-related API tests
- `npm run test:validation` runs the validation-focused expense test

## Test Flow

The project uses a custom auth fixture to:

1. Create a Playwright API request context
2. Log in to the API using `API_EMAIL` and `API_PASSWORD`
3. Extract the JWT token from the response
4. Create an authenticated request context with the bearer token
5. Reuse this context across tests for validated endpoints

## Sample Test Coverage

This repository tests:

- Login API returns a valid JWT token
- Expense list API returns a successful response
- Expense creation API works with valid payloads
- Expense validation scenarios for invalid/missing data

## Reporting

Playwright HTML reports are generated as part of the configuration. To view the latest report:

```bash
npm run report
```

## Notes

- The Playwright config loads environment variables from `.env` automatically.
- The test suite is configured with a single worker to keep API interactions predictable.
- Traces are retained only on failure for debugging purposes.
